# Nextcloud update for schools

`idea-nextcloud-update-1.8-31.0.14.pdf` ("Nextcloud update for schools"): a short note for school operators and teachers about the Nextcloud same-major patch update to App version 1.8-31.0.14 (31.0.1 to 31.0.14). It says what changes, how long Nextcloud is unavailable, that the box makes a safety copy on the same disk as Nextcloud (no Backup Disk is needed), and that a failed update rolls back by itself.

This is a draft for Steve and Koen. It has not been given to schools yet.

Build: `python3 build.py` (uses `docs/house-style`).
